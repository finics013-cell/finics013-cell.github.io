Café Caramello
Visão geral

Um projeto aplicado a uma necessidade real

Este trabalho foi desenvolvido para um cliente real, levando conhecimentos de programação e desenvolvimento web para uma aplicação prática de divulgação comercial.

01 / CONTEXTO

Cliente real

Site desenvolvido para apoiar a presença digital de um vendedor dos produtos Café Caramello.

02 / OBJETIVO

Apresentação comercial

Criar um espaço digital para apresentar o negócio e facilitar o acesso dos visitantes às informações disponíveis.

03 / ENTREGA

Site publicado

Aplicação web desenvolvida com Flask e disponibilizada on-line para acesso pelo navegador.

Desenvolvimento

Da programação à aplicação

O projeto envolveu a construção de uma aplicação web com Python e Flask, utilizando tecnologias de front-end para estruturar e apresentar o conteúdo no navegador.

A proposta foi transformar a necessidade comercial do cliente em uma página acessível pela internet, reunindo a apresentação do negócio em um único endereço.

A aplicação publicada permite consultar o resultado do desenvolvimento diretamente no navegador.

Visão profissional

Desenvolver para um cliente exige mais do que escrever código: é necessário compreender a finalidade do projeto, organizar informações e entregar uma solução que possa ser utilizada fora do ambiente de desenvolvimento.
