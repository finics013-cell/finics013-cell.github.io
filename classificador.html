Classificador de Notícias

Projeto de classificação automática de notícias em português usando Python. O trabalho envolve exploração e preparação de dados textuais e o desenvolvimento de um fluxo de Processamento de Linguagem Natural para identificar categorias de notícias.

Visão geral

Um projeto prático de classificação de texto aplicado a notícias em português.

01 · Objetivo

Desenvolver um classificador capaz de associar uma notícia à sua categoria a partir de informações textuais. O projeto explora como técnicas de Machine Learning e Processamento de Linguagem Natural podem transformar texto não estruturado em informação organizada.

Problema de negócio

A classificação automática pode ajudar a organizar grandes volumes de notícias, facilitar buscas e reduzir o esforço manual de categorização.

02 · Base de dados

O projeto utiliza o dataset público News of the Site Folha UOL , com notícias publicadas pela Folha de S.Paulo.

  • Volume original: 167.053 registros.
  • Variáveis principais: título, texto e categoria.
  • Tipo de dado: texto não estruturado acompanhado de rótulos.

A exploração inicial da base ajuda a compreender sua estrutura, verificar a qualidade dos registros e identificar problemas que precisam ser tratados antes da modelagem.

03 · Preparação dos dados

Antes de treinar um modelo, é importante verificar a consistência dos dados e lidar com valores ausentes. Essa etapa evita que problemas da base prejudiquem o restante do fluxo.

  • Inspeção das colunas e dos tipos de dados.
  • Identificação de valores ausentes na coluna de texto.
  • Tratamento de 765 registros com texto ausente.
  • Verificação das categorias disponíveis para classificação.
  • Preparação dos dados textuais para as etapas seguintes.
Decisão importante

O tratamento de dados precisa respeitar o contexto. Valores ausentes não devem ser removidos ou preenchidos automaticamente sem avaliar como isso afeta o problema.

04 · Processamento de Linguagem Natural

Como as notícias são textos em português, o projeto utiliza técnicas de NLP (Natural Language Processing), também chamado de PLN em português, para preparar os dados e trabalhar com informação textual.

  • Python: linguagem utilizada para construir o fluxo do projeto.
  • Pandas: manipulação, inspeção e preparação dos dados.
  • NLTK: ferramentas de processamento de linguagem natural, incluindo recursos para texto.
  • Machine Learning: abordagem para aprender padrões e prever categorias.

O objetivo é aprender padrões presentes nos dados de treinamento e avaliar a capacidade do classificador de atribuir categorias a notícias que não foram usadas durante o treinamento.

05 · Aprendizados e próximos passos

O projeto reúne etapas importantes de um fluxo de Ciência de Dados: compreensão do problema, exploração da base, tratamento dos dados textuais, preparação para modelagem e aplicação do classificador.

  • Prática com um dataset real de notícias em português.
  • Experiência com preparação e tratamento de dados textuais.
  • Aplicação de conceitos de Machine Learning e NLP.
  • Desenvolvimento de uma aplicação web com Flask para apresentar o projeto.

Próximos passos possíveis: documentar as métricas de avaliação, detalhar o desempenho por categoria e comparar erros do modelo para identificar oportunidades de melhoria.
